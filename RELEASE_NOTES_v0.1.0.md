# SS2do v0.1.0

Initial public release of the screenshot-to-action workflow.

## Highlights

- OCR flow for screenshots and camera images
- Suggested query and action bucket from recognized text
- Manual fallback: save actionable using query only
- Bucketed actionable queue by action type
- Screenshot thumbnail stored with each actionable item
- Android share target support (share screenshot directly to SS2do)
- Included debug APK for direct testing

## Included APK

- `releases/SS2do-debug.apk`

## Notes

- This is an MVP focused on local-first usage and accountability workflows
- Data is stored locally on device/browser storage in this version
